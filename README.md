# :milky_way: Space Explorer
**Space Explorer** is a single-page web application for exploring space content using NASA APIs. Built entirely using **HTML**, **BOOTSTRAP**, and **JavaScript** without any frameworks. All DOM elements are dynamically created using JavaScript, and data is fetched via **XHR (XMLHttpRequest)**.
---
## :busts_in_silhouette: Users
- **All users** can:
  - Browse space-related media (images, videos)
  - Search for media by keyword
  - Filter content by date, media type, or mission
  - View details of each item (title, description, date)
  - Add items to **Favorites**
  - Create **custom albums** of favorite media
  - Switch between **grid** or **list** views
  - Stay updated with the latest **NASA news**
---
## :dart: Features
- :mag: **Advanced Search & Filters**
  - Filter by keyword, date range, media type (image/video), or mission name.
- :camera_with_flash: **Media Browser**
  - Pulls from NASA APIs like APOD, Image and Video Library.
  - Responsive grid or list view toggle.
- :heart: **Albums & Favorites**
  - Save favorite items to local albums (using `localStorage`).
  - Create and rename personal collections.
- :receipt: **Detailed Media Info**
  - Each media card expands to show full description, source, date, and type.
- :newspaper: **NASA News Feed**
  - Integration with NASA’s news and updates.
